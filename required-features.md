# No Man’s Drive — required features

## User request

- Build the full game in `requiredtruth/no-mans-drive-game`. Posting directly to `main` is approved.
- Match every feature and gameplay detail of Nomad Drive as closely as possible, with a very high quality presentation, high-resolution visuals, and free online textures, shaders, and models.
- Add roaming wildlife the player can hunt.
- Let players establish a camp with a working campfire.
- Let players construct complete houses.
- Save all user requirements in `required-features.md`.
- Publish a GitHub release with an installable Android APK.

## Reference features to reproduce

- First-person traversal and drivable RV. Start with a rundown RV and repair, maintain, upgrade, and customize its parts.
- Interactive RV interior with kitchen, stove, refrigerator, toilet, seating, and furniture.
- Procedurally generated post-apocalyptic world with varied starts, roads, abandoned locations, resources, distinct biomes, climates, and ecosystems.
- Solo and online co-op for up to four players.
- Survival needs, resource gathering, crafting, cooking, fishing, coffee preparation, pot gardening from seeds, and harvesting produce.
- Controller support, adjustable difficulty, camera comfort, independent audio controls, and save-anytime behavior. Provide Android touch controls.
- Continue the parity audit against the playable reference, its settings, and release notes. The public descriptions establish a baseline for the audit.

## Added gameplay

- Roaming wildlife with behavior appropriate to its biome, a hunting loop, and harvestable resources.
- Place camps and use campfires as light, heat, and cooking stations.
- Build persistent, enterable houses using floors, walls, doors, windows, and roofs with placement preview, rotation, and resource costs.

## Release acceptance

- Use original or appropriately licensed assets and record source, license, and attribution for each external asset.
- Verify gameplay, save and load, controls, and performance on Android. Test co-op with multiple clients.
- Tag the approved `main` commit, publish a GitHub release, and verify that the attached Android APK installs and launches.
