# Item backlog

The full list of items to build and add to No Man's Drive in future versions, as supplied by the project owner. Keep these files as the source list; work through them version by version.

| File | Covers |
|---|---|
| `part-1-master-item-list.txt` | 1–10: raw resources, chemistry and fuels, food and cooking, medical, firearms and ammo, tools and melee, apparel and armor, mobile base gear, machinery and power, vehicle and engine parts |
| `part-2-expansion-and-base-building.txt` | 11–14: base building, roadway salvage and chassis parts, navigation and wilderness gear |
| `part-3-electronics-salvage-and-mods.txt` | 15–18: electronics and wiring, salvage, vehicle armor upgrades, hunting byproducts, camp cooking gear |

Each item needs a real 3D model and texture, an entry in `game/scripts/data.gd`, a model in `game/scripts/items.gd` (or a structure in `structure.gd` for placeable furniture), and a place in the loot tables or a recipe.
